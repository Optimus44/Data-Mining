## Reproducing the results

1. Install R (>= 4.0) and the `arules` package:
   ```r
   install.packages("arules")
   ```
2. From the project root, run:
   ```bash
   Rscript scripts/analysis.R
   ```
   This regenerates everything in `results/`.
3. Recompile the report:
   ```bash
   cd report
   latexmk -pdf -interaction=nonstopmode report.tex
   ```

## Method summary

- **Data**: 9,835 transactions, 169 unique items, loaded with `arules::read.transactions()`
  (basket format).
- **Frequent itemsets**: mined with `apriori()`, minimum support = 0.02, minimum length = 2.
- **Association rules**: minimum support = 0.02, minimum confidence = 0.25.
- All support/confidence/lift values in the report are taken directly from these outputs.
