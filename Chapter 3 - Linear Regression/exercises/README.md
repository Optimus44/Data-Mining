# Chapter 3 Exercises

This folder contains the completed Chapter 3 exercises for the Data Mining
module's Linear Regression topic.

## Contents

- [chapter03_exercises.Rmd](chapter03_exercises.Rmd) - source R Markdown file.
- [chapter03_exercises.pdf](chapter03_exercises.pdf) - compiled exercise submission.
- [chapter03_exercises.tex](chapter03_exercises.tex) - generated LaTeX source.

## Exercises Covered

The document includes:

- Exercise 1: null hypotheses for the multiple regression model in Table 3.4.
- Exercise 6: the property that the least squares line passes through the
  sample means.
- Exercise 11: regression through the origin.

## How to Use

Open [chapter03_exercises.Rmd](chapter03_exercises.Rmd) in RStudio and run the
code chunks in order. Select **Knit** to regenerate the PDF and LaTeX output.

The exercises use examples and calculations defined in the document. No
external dataset is required for this exercise set.

See the [Chapter 3 README](../README.md) for the overview of the lab and
exercise materials.
