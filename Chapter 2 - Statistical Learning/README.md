# Chapter 2 — Statistical Learning

Exercises 1 and 10 from *An Introduction to Statistical Learning with
Applications in R* (2nd edition), for the Data Mining course.

## Contents

| File | Description |
|---|---|
| `ch02_exercises.Rmd` | Source R Markdown — conceptual (Ex. 1) and applied (Ex. 10) answers, with code, output, and explanations. |
| `ch02_exercises.tex` | Intermediate LaTeX generated by knitting the Rmd (kept via `keep_tex: true`). |
| `ch02_exercises.pdf` | Final knitted PDF — the submitted deliverable. |

## Exercises covered

- **Exercise 1**: Conceptual — flexible vs. inflexible statistical learning
  methods under four scenarios (large *n*/small *p*, small *n*/large *p*,
  non-linear relationships, high error variance), justified via the
  bias-variance-irreducible error decomposition of expected test MSE.
- **Exercise 10**: Applied — exploratory analysis of the `Boston` housing
  data set (`ISLR2` package): dimensions, pairwise scatterplots, crime-rate
  associations, predictor ranges, Charles River tracts, pupil-teacher
  ratio, the lowest-value tract, and large-home tracts.
